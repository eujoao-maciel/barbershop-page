<p align="start">A barbershop website template with WhatsApp-integrated appointment booking.</p>

<h2 align="start">About</h2>
<p align="start">
barbershop-page is a front-end template built for barbershops that want a professional online presence without complexity. The page covers the essentials — services, gallery, and contact — and routes appointment requests directly to WhatsApp.
</p>

<h2 align="start">Features</h2>
<table align="start">
   <tr>
     <td>WhatsApp booking </td>
     <td>Responsive layout</td>
     <td>Services section</td>
     <td>Gallery</td>
     <td>Reusable template</td>
   </tr>

   <tr>
     <td>Sends a pre-filled message to schedule appointments directly via WhatsApp</td>
     <td>Works on mobile and desktop</td>
     <td>Lists available cuts and prices</td>
     <td>Showcases the shop's work</td>
     <td>Easy to rebrand with a new name, number, and colors</td>
   </tr>
</table>
